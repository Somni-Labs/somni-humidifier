# V3.3 Touch Button Wire Channels — Design Spec

## Summary

Add guided wire channels with retaining clips inside the top shell, routing TTP223 capacitive touch button wires from their module pockets along the ceiling interior toward center, then dropping vertically to the electronics tray level. Two independent channels (one per button), no merge point.

## Principles

1. **Guided routing** — wires follow a defined path, not free-floating
2. **Clip retention** — small overhang lips snap wires in, prevent them falling out during assembly
3. **FDM-friendly** — channels are simple grooves in ceiling, clips print as overhangs (≤1mm, no support needed)
4. **Independent paths** — each button gets its own channel, simpler geometry, no junction

## Channel Layout

### Per-Button Channel Path

Each channel runs from the button pocket to a vertical drop point:

1. **Start:** Exit hole in floor of TTP223 module pocket (4mm wide slot)
2. **Ceiling run:** Groove along ceiling interior surface, heading +Y (toward rear/center)
   - From Y = -25mm (button position) to Y = 0mm (center of shell)
   - At X = ±17.5mm (same X as button, straight back)
3. **Vertical drop:** 90° turn downward, groove continues down the nearest interior surface
   - Drop runs from ceiling (Z = TOP_H - WALL) down to Z = 10mm (below tray level)
   - Wires exit at bottom, route freely the short distance to ESP32 GPIO pins on tray

### Two Channels Total

| Channel | Button | X position | Y run | Drop location |
|---|---|---|---|---|
| Left | Power button | -17.5mm | Y=-25 to Y=0 | Down at X=-17.5, Y=0 |
| Right | Mist button | +17.5mm | Y=-25 to Y=0 | Down at X=+17.5, Y=0 |

## Channel Dimensions

| Feature | Value |
|---|---|
| Channel width | 4mm (fits 3× 26AWG wires comfortably) |
| Channel depth | 3mm (into ceiling/wall thickness) |
| Exit slot (from button pocket) | 4mm × 3mm opening in pocket floor |
| Ceiling run length | 25mm (Y=-25 to Y=0) |
| Vertical drop height | ~45mm (ceiling to below tray) |

## Retaining Clips

Small overhang lips along the channel that snap wires in place.

| Feature | Value |
|---|---|
| Clip overhang | 1mm (into channel from one side) |
| Clip thickness | 1mm |
| Clip spacing | 15mm along channel run |
| Clip count per ceiling run | 2 (at Y=-17 and Y=-2) |
| Clip count per vertical drop | 3 (evenly spaced over 45mm) |
| Open side | Top of channel (ceiling runs); outer side (vertical drops) |

### Clip Cross-Section (ceiling run, looking along Y axis):
```
    ceiling interior surface
    ═══════╤════╤═══════════
           │    │  ← channel (4mm wide, 3mm deep)
           │    │
      clip ╞══  │  ← 1mm overhang from left side
           │    │
           ╧════╧
```

Wires press past the clip overhang to seat in the channel. The overhang is thin enough to flex during insertion but rigid enough to retain.

## Integration with Existing Geometry

### Top Shell Modifications

The channels are cut INTO the existing top shell ceiling and interior walls. No new separate parts.

**In `build_top_shell()`:**
1. After the TTP223 module pocket loop, add wire exit slots in pocket floors
2. Add ceiling groove from each button pocket running +Y to center
3. Add vertical drop grooves at (±17.5, 0) running down interior
4. Add clip features (small box protrusions into the channel at intervals)

### Clearance Checks

- Channels at X=±17.5 are in the center zone (DIVIDER_WET_X = -21.8, so both channels are right of divider)
- Channels don't interfere with: mist channel, fill chute, bottle wells, storage compartment
- Vertical drops at Y=0 are mid-shell, away from magnet pockets and pin holes
- Channel depth (3mm) doesn't exceed wall thickness (WALL = 3mm for ceiling) — channels are cut to 3mm depth in areas where ceiling is already thinned for buttons; limit to 2.5mm to leave 0.5mm shell

### Adjusted Channel Depth

Since the top shell ceiling is only WALL (3mm) thick:
- Ceiling run depth: 2.5mm (leaves 0.5mm shell on exterior)
- Vertical drop depth: 3mm (interior walls are thicker, no exterior exposure)

## File Changes

Single file: `designs/v2-oil-diffuser.py`

### Constants

Add after existing touch button constants:

```python
# --- Touch button wire channels ---
TOUCH_WIRE_CH_W = 4.0        # channel width
TOUCH_WIRE_CH_D = 2.5        # channel depth (ceiling run, leaves 0.5mm shell)
TOUCH_WIRE_DROP_D = 3.0      # channel depth (vertical drop)
TOUCH_WIRE_CLIP_OVERHANG = 1.0  # clip lip overhang into channel
TOUCH_WIRE_CLIP_THICK = 1.0  # clip lip thickness
TOUCH_WIRE_CLIP_SPACING = 15.0  # spacing between clips
```

### `build_top_shell()`

After the existing touch button pocket loop:

1. Cut wire exit slot in floor of each button pocket (4mm × 3mm hole connecting pocket to ceiling run below)
2. Cut ceiling run groove: box(TOUCH_WIRE_CH_W, channel_length, TOUCH_WIRE_CH_D) along ceiling interior from each button Y to Y=0
3. Cut vertical drop groove: box(TOUCH_WIRE_CH_W, TOUCH_WIRE_DROP_D, drop_height) running from ceiling down to Z≈10
4. Add clip protrusions: small boxes (1mm × 1mm × TOUCH_WIRE_CH_W) that protrude into channel at clip positions — built by unioning small geometry, then NOT cutting those areas from the channel

**Clip implementation:** Cut the full channel groove first. Then union small clip lips back at the clip positions. Each clip is a small rectangular bar spanning the channel width, protruding 1mm inward from one channel wall, 1mm thick along the channel run direction.

## New Parts

None — all geometry is cut into/added to the existing top shell.

## Print Orientation Note

Top shell prints upside down (ceiling face on bed). This means:
- Ceiling channels face UP during printing → clean groove, no supports
- Clip overhangs are 1mm horizontal extensions → print fine without support
- Vertical drop channels are oriented horizontally during print → clean cut
