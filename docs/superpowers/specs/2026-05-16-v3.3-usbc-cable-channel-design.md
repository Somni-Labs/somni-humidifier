# V3.3 USB-C Power Cable Channel — Design Spec

## Summary

Add a guided cable channel in the base interior routing the USB-C power cable from the rear wall port to the PD+Buck converter pocket on the electronics tray. Includes a strain relief hook at the port end and retaining clips along the run.

## Principles

1. **Short direct path** — rear wall straight inward to tray, no detours
2. **Strain relief** — cable loops around a hook post so pulling the cord doesn't stress the PD board
3. **Clip retention** — small overhang lips keep cable seated during assembly
4. **FDM-friendly** — channel is a simple groove in floor, hook is a cylindrical post

## Channel Layout

### Route

1. **Start:** USB-C port cutout on rear wall (+Y), center zone
2. **Run:** Straight inward (-Y direction) along base interior at tray Z level
3. **End:** Tray edge, directly below PD+Buck pocket on electronics tray

### Positions

| Reference | Value |
|---|---|
| USB-C port X | `(_pump_left_col_cx + _pump_right_col_cx) / 2` (center of pump columns) |
| USB-C port Z | `TRAY_Z + TRAY_FLOOR + 3` = 37mm (center of port opening) |
| Channel Z (floor) | `TRAY_Z` = 32mm (sits on the ledge below tray) |
| Channel Y start | Interior face of rear wall: `MEETING_D / 2 - WALL` |
| Channel Y end | ~15-20mm inward from rear wall (tray rear edge) |
| Run length | ~18mm |

## Channel Dimensions

| Feature | Value |
|---|---|
| Channel width | 8mm (USB-C cable ~4mm OD + routing clearance) |
| Channel depth | 5mm (cable sits below floor level, protected) |
| Channel length | ~18mm (rear wall to tray edge) |
| Cut into | Base interior floor at TRAY_Z level |

## Strain Relief Hook

A cylindrical post near the port end that the cable wraps around in a U-shape. This absorbs pull force on the external cable without transmitting it to the PD board solder joints.

| Feature | Value |
|---|---|
| Post diameter | 4mm |
| Post height | 8mm (taller than channel depth, cable wraps around mid-height) |
| Position | In channel, 5mm inward from rear wall |
| Clearance | 2mm gap between post and channel walls on each side |

### How it works
```
    Rear wall (port)
    ════════════╗
                ║ cable enters
         ┌──┐  ║
         │  │←─╝ cable wraps around post
         │  │
         └──┘  
            ╚═══ cable continues to PD+Buck
```

The cable enters from the port, wraps around the post (180° loop), then continues forward to the tray. Any pull on the external cord is absorbed by the post, not the board connection.

## Retaining Clips

| Feature | Value |
|---|---|
| Clip overhang | 1mm (into channel from one side) |
| Clip thickness | 1mm (along channel run direction) |
| Clip count | 2 (one near port, one near tray end) |
| Clip positions | Y = rear_wall - 3mm, Y = rear_wall - 15mm |

Same style as touch button wire channel clips — small lips that the cable presses past.
