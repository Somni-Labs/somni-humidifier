# V3.3 Bottle Collar Insert — Design Spec

## Summary

Replace the plain retaining rings in each ceiling well with a threaded collar insert. Bottles drop in cap-first and are held by an O-ring + retention lip. Inlet tubes exit straight down through the collar center hole, then route toward the divider wall (-X direction) for pump access. The outer wall side stays clear for bottle removal/service.

## Principles

1. **Universal fit** — any standard 15ml bottle with 18-410 neck finish
2. **Permanent install** — collar screws into ceiling once, bottle drops in/out
3. **Secure retention** — O-ring friction + lip shelf, holds ~50g bottle against gravity
4. **Tube clearance** — center exit hole, no interference with collar threads
5. **FDM-printable** — coarse threads (M22x2.5), print vertically for clean profile

## Collar Anatomy (Top to Bottom)

### 1. Knurled Flange (top)
- OD: 24mm (matches existing well diameter)
- Height: 2mm
- Sits flush with ceiling inner surface
- Diamond knurl pattern on outer rim for grip
- Visible from above when top shell is removed

### 2. Threaded Body
- OD: 22mm (thread major diameter)
- Thread: M22x2.5 (coarse, ~3 full turns)
- Height: 8mm
- External threads mate with internal threads in ceiling well
- Printed vertically — layer lines run along thread helix for strength

### 3. Internal Bore
- ID: 18.5mm (18mm bottle cap + 0.5mm clearance)
- Smooth wall — bottle cap slides in without catching
- Full depth from flange top to lip

### 4. O-Ring Groove
- Position: 4mm below flange top (mid-height of bore)
- Groove width: 2.0mm
- Groove depth: 1.2mm (into collar wall)
- O-ring: 18mm ID × 1.5mm cross-section (standard size)
- Provides lateral snugness — no rattle, gentle friction on neck

### 5. Retention Lip
- Position: bottom of bore
- Lip width: 1.75mm inward (reduces bore from 18.5mm to 15mm opening)
- Lip thickness: 1.5mm
- Bottle cap rim (18mm OD) rests on this lip
- Prevents fall-through even if O-ring degrades
- Slight chamfer on top edge for guided bottle insertion

### 6. Tube Exit Hole
- Diameter: 4mm (fits 3mm OD silicone tube with clearance)
- Position: dead center of bottom face, below lip
- Tube threads through bottle cap center, through this hole, then hangs below collar

## Ceiling Well Changes

### Remove
- Existing retaining rings (15mm tall, 2mm wall cylinders) — replaced by collar

### Modify
- Well bore depth: 3mm → 12mm (to accept full threaded body + flange flush-mount)
- Well bore diameter: stays 24.8mm (flange OD 24mm + 0.4mm tolerance per side)
- Add internal threads: M22×2.5, cut into well bore wall (8mm deep, starting 2mm below ceiling surface)
- Flange recess: 2mm deep, 24.8mm diameter (flange sits flush, doesn't protrude below ceiling)

### Keep
- Well positions (3+2 grid, unchanged)
- Well center-to-center spacing (BOTTLE_Y_SPACING unchanged)
- Bottle body still hangs below collar in open interior

## Inlet Tube Routing Fix

### Current (incorrect)
- Tubes exit cap top, route toward outer wall (+X)
- Blocks bottle access from the service side

### Corrected
- Tubes exit cap top center, go UP through collar tube hole
- Short stub above collar (2-3mm)
- Bend TOWARD DIVIDER WALL (-X direction)
- Run down outside bottle body on divider side
- Drop to pump level
- Horizontal jog to pump position

### Logic Change
- Force `_ext_x` toward divider: `_ext_x = bx - (BOTTLE_DIA / 2 + 2)` always (regardless of pump X position)
- Tubes route over the -X side of the bottle body
- This keeps the +X (outer wall) side clear for grabbing/removing bottles

## Assembly Sequence

1. **Print collars** (5×, vertical orientation for clean threads)
2. **Install O-rings** into collar grooves (press-fit, one per collar)
3. **Screw collars into ceiling wells** (hand-tight, flange flush with ceiling)
4. **Thread inlet tube through bottle cap** (tube inside bottle, exits cap center)
5. **Drop bottle into collar** cap-first — cap rim seats on lip, O-ring grips neck
6. **Route tube** through collar center hole, bend toward divider, run to pump
