# V3.3 "Compact Grid" — Design Spec

## Summary

Shrink the Somni Oil Diffuser from 160x160mm (V3.2) to **130x104mm** by switching from a 1x5 pump row to a 2+3 pump grid and tightening all margins. Same three-part enclosure (base + electronics tray + top shell), same cyberpunk "Night City" aesthetic, same BOM. Bottles move from a single row to a 3+2 grid in the top shell ceiling. Mist chimney, fill chute, and exhaust shrink to fit the narrower wet zone. **47% area reduction**.

## Base Layout

Two zones separated by a single divider wall at `DIVIDER_WET_X`:

### Wet Zone (left of divider, ~33mm wide at meeting line)

- Water reservoir: full zone depth, ~164mL capacity
- Atomizer mount: 24mm through-hole at X=-38.1, Y=0 with 2mm seal ring
- Atomizer clearance: 4.4mm to both left wall and divider

### Center Zone (right of divider, 75mm wide at meeting line)

**Lower level (floor to Z=32):** 2+3 pump grid

```
              Left col (2)    Right col (3)
              near divider    near wall
  Y = +26                      [pump 5]
  Y = +13      [pump 2]
  Y =   0                      [pump 4]
  Y = -13      [pump 1]
  Y = -26                      [pump 3]
```

- Left column center X: `center_left + 1 + PUMP_BODY_W/2` (1mm clearance from divider)
- Right column center X: `left_col_cx + PUMP_BODY_W/2 + COL_GAP + PUMP_BODY_W/2`
- Right column right edge has 1mm clearance to outer wall
- Each pump sits in a pocket with shelf ledges (same retention as V3.2)

**Upper level (Z=32 to Z=52):** Electronics tray (lift-out shelf)

- Tray width: 73mm (matches pump grid X span + clearance)
- Same registration tab + ledge system as V3.2

### Tubing Pass-Throughs

Each pump's output tube must route through the divider to the wet zone (reservoir). **5 tubing holes** in the divider wall, one per pump:

- Left column pumps (2): holes at Y=-13 and Y=+13
- Right column pumps (3): holes at Y=-26, Y=0, Y=+26
- All holes at Z = `FLOOR_H + divider_h - 8` (near top of divider for gravity-assisted flow)
- Hole diameter: 6mm (3mm radius, same as V3.2)

The tubing from right-column pumps routes across the center zone floor before passing through the divider. A **tubing channel** runs along the base floor parallel to the divider (at X = `divider_x + WALL_INNER/2 + 3`) to collect these runs:

- Channel dimensions: 4mm wide x 3mm deep, cut into the floor
- Runs from Y=-30 to Y=+30 (spanning all pump positions)
- Individual spur channels (3mm wide x 3mm deep) branch from each right-column pump to this collector channel
- Left column pumps route directly to divider holes (short run, no floor channel needed)

### Wire Channel Network (Base Floor)

Wires route from the atomizer (wet zone) to the electronics tray (center zone upper level):

1. **Atomizer spur**: 3x3mm channel from atomizer position (X=-38.1, Y=0) east to the divider
2. **Cross-divider wire port**: 5mm wide x 4mm tall opening through the divider at Z=`FLOOR_H+1`
3. **Tray wire pass-through**: opening in divider wall at tray Z level for wires between base floor and tray

The gap between the two left-column pumps (Y=-13 to Y=+13, a 26mm-3mm=23mm open space at Y=0) provides a natural wire routing corridor from the divider port up to the tray.

### Wire Channels (Electronics Tray)

Same as V3.2:
- Power bus channel (Y-axis) connecting all board pockets
- Cross-channel (X-axis) connecting left and right columns
- Wire drop hole: through-hole in tray floor for atomizer wire from base

## Electronics Tray

Same lift-out shelf concept, slightly wider:

- Tray interior width: ~73mm (was ~65mm effective in V3.2)
- Two-column board layout unchanged:
  - Left column: ESP32 DevKit (55x28mm)
  - Right column: MOSFET board (50x26mm), PD trigger + buck converter (Z-stacked), atomizer driver (35x25mm), BME280 (15x12mm)
- 4 corner legs rest on ledges (left: divider wall, right: outer wall)
- 4 registration tabs slot into wall slots
- Rail slots + snap tabs for PCB retention
- Extra 8mm width padding provides better wire routing space

## Top Shell

Two zones matching the base divider:

### Left Zone: Mist + Fill

- **Mist chimney**: 25mm bore (was 30mm) with 2.5mm walls, centered above atomizer
- **Fill chute**: 25x30mm top opening (was 35x40mm), funnel to 14x20mm bottom. Lip height 3mm.
- **Exhaust port**: 30x20mm (was 40x25mm) with chevron vanes (3 vanes, same pattern)
- **Hex mesh**: same pattern over exhaust, scaled to fit smaller opening

### Right Zone: Bottles + Storage

**3+2 bottle grid** in ceiling (was single 1x5 row):

```
              Row 1 (3)       Row 2 (2)
              near divider    near wall
  Y = +26      [bottle 3]      [bottle 5]
  Y =   0      [bottle 2]
  Y = -26      [bottle 1]      [bottle 4]
```

- Row 1 center X: `top_divider_x + WALL_INNER/2 + clearance + BOTTLE_WELL_DIA/2`
- Row 2 center X: `row1_x + BOTTLE_WELL_DIA/2 + BOTTLE_ROW_GAP + BOTTLE_WELL_DIA/2`
- Row 2 bottles offset to Y=-26 and Y=+26 (nest between row 1 positions)
- Each well: 24.8mm diameter, 3mm recess into ceiling
- Each retaining ring: 15mm tall, hangs down from ceiling
- Grid footprint: ~52mm (X) x ~77mm (Y) in 73x81mm available space

### Magnets

4 magnets (down from 6), one per side:
- Front: (0, -MD/2 + 20)
- Back:  (0, +MD/2 - 20)
- Left:  (-MW/2 + 20, 0)
- Right: (+MW/2 - 20, 0)

### Alignment Pins

2 pins (down from 4 implied by corners), diagonal placement for keying.

## LED Strip Channel

Same continuous perimeter loop, dimensions unchanged (12mm wide x 5mm deep). Recalculated positions for smaller footprint — runs along all 4 inner walls near the top of the base.

## Touch Buttons

Same 2x TTP223 capacitive on front face, 35mm spacing. Front face is now at Y=-52 (base) / Y=-44.5 (meeting line). Still fits.

## USB-C Port

Rear wall of center zone, same 12mm x 7mm cutout. Position recalculated for new center zone bounds.

## Rubber Feet

4 feet, inset reduced from 20mm to **15mm** to fit smaller base footprint.

## Component Visualization

Same color scheme as V3.2. Pump visualization changes from single row to 2+3 grid. Bottle visualization changes from single row to 3+2 grid. Tubing channel visualization added in magenta. All wire channel visualizations recalculated for new positions.
